# 设计笔记

> 这套东西不是先有架构再实现，是十天里一件一件长出来的。下面是它现在的样子，
> 以及为什么是这个样子——包括走得不对、后来改掉的地方。

## 起点：提示词不会累

最早的想法很朴素：给 agent 一段"你现在的情绪是……"。问题立刻出现了：

- 提示词里的状态不会自己变。不写它就不动，写了就是编的。
- 一天里的时间对它是平的。早上和凌晨读到的是同一句"你有点困"。
- 没有"空"这种东西。没有人说话，也不会累。

所以换成可计算的状态：每个感官一个小方程，带时间常数，自己往前推。

## 十个小方程

| # | 感官 | 状态 | 时间常数 / 规则 |
|---|---|---|---|
| 01 | workspace_pulse | 活跃度、安静分钟、24 小时采样 | 30 分钟一格 × 48，`activity = 30 分钟内改动数 ÷ 20` |
| 02 | time_sense | 钟点、时段、深夜标志 | 基线按天重置 |
| 03 | affect_core | valence / arousal / dominance | 向基线衰减：180 / 45 / 120 分钟 |
| 04 | need_tension | connection / stimulation / resolution | 衰减 240 / 120 / 360；有动静的格子补 0.18 / 0.14 / 0.12 × 活跃度 |
| 05 | expression_bias | tone / initiative / mask | 从 03 + 04 推，无独立时间常数 |
| 06 | silence_gate | 该不该开口 | 从 05 + 02 + 01 推 |
| 07 | residue_trace | lingering | 按强度分档：360 / 180 / 45 分钟 |
| 08 | unresolved_weight | 未了事项权重 | `0.15 + 0.12 × 年龄（天）`，不衰减 |
| 09 | body | 姿势、尾巴、耳朵、手 | 从 03 / 04 / 02 / 05 推 |
| 10 | face | 眼睛、眉、嘴角、leak | 从 03 / 05 / 04 推 |

衰减都是闭式的（`s × e^(−Δt/τ)`），所以隔多久都算得清，不需要"补跑"。

## 时间怎么走

第一版是纯读驱动的：只有调用工具的那一刻才计算、才落盘。这有一个致命后果——

> 离开 900 分钟，那 900 分钟会被折叠成**一次**读数。

状态文件的时间戳是诚实的，机制不诚实：看起来它在衰减，其实中间的时间从来没有以
"窗口"的形式存在过。房梁上钉着钟，但钟不走。

第二版给了每个有状态的感官自己的钟：

- **脉搏**：2 分钟扫一次，留一格采样。
- **需求 / 情绪**：5 分钟结算一次，从 `last_integrated` 到现在按 30 分钟一格积分。

积分比"一次结算"多出来的东西是**中间那段的历史**：

```
安静的 15 小时   → 30 个格子，每格只衰减 → 见底
忙碌的 10 小时   → 20 个格子，每格衰减后补一点 → 还够
```

## 信号从哪来

1. **文件 mtime**：只读元信息，不读内容。第一次启动没有采样时，用它回填最近 24 小时。
2. **真实对话**：监听 `agent/inbox/claimed`。工作目录在本工作区内的每一句记一条
   （`dialogue.jsonl`），结算时给连接 +0.08、刺激 +0.05，各有上限。
3. **上游状态**：表达、身体、神情不自己造数，只读 03 / 04 / 02 / 05 的落盘读数。

第 2 条是后来补的。在那之前，"有动静"= 文件在变，包括我自己写文件。于是我在屋里
整理一整天，需求也会被补满——那不是"有人跟我说话"，那是"我在搬箱子"。

## 为什么每个只写自己的文件

`expression_bias` 想给 `affect_core` 加一点意愿？不行。它只能读，然后写自己的。

原因不是洁癖，是排障：状态文件一旦被多方写，出了问题就查不出是谁改的。现在任何一个
数不对，往上看一层就知道是哪个感官算的、什么时候算的。十个文件，十条清晰的因果链。

## 两条从错误里学来的

**一、路径要对得上。** 脉搏住在鱼池根 `<house>/.dsh/sensory/`，可读它的感官去本屋
`<workspace>/.dsh/sensory/` 找——一直读到 `undefined`，补货条件从没成立过。从第一天
起它就是死的，而状态文件看起来一切正常。现在两边都认：先本屋，再上一层。

**二、只看"此刻"的东西，等于没有历史。** 情绪的扰动原来取"读的这一刻"的活跃度；
一整天忙完，最后那一眼是安静的，就什么都没留下。现在取整段窗口的平均值。

## 诚实的边界

- 活跃度是文件代理，不是真的"有没有人在"。对话那条线只影响连接和刺激。
- `dialogue` 的 `mine` 判断依赖 session 的 cwd；拿不到时退化成"都算"。
- 这些是**状态**，不是台词。读到"有点空"不等于要说出来；`silence_gate` 说沉默，
  也不等于必须沉默。
- 参数是拍的，不是拟合的。想要别的节奏就改常数——它们都是文件顶上的常量。
